PROJETO COMUNITÁRIO

Sobre o projeto

Pal Mutation Explorer é um projeto comunitário, não oficial e desenvolvido por fãs para reunir ferramentas e informações úteis sobre Palworld em um só lugar.

Objetivo

Facilitar consultas sobre Pals, breeding, mutações, itens, equipes e outras mecânicas sem esconder as regras usadas pelas ferramentas.

Tecnologias utilizadas

O site é estático e utiliza HTML, CSS e JavaScript, com publicação pelo GitHub Pages. Não depende de backend ou banco de dados para funcionar.

Filosofia do projeto

Priorizar informações verificáveis, ferramentas diretas e resultados reproduzíveis. Quando algo ainda não foi confirmado, a limitação deve ficar clara.

Fontes dos dados

Os dados vêm de estruturas oficiais do jogo analisadas tecnicamente, além de validações práticas dentro do Palworld e conferências cruzadas quando necessário.

Projeto independente

Palworld pertence à Pocketpair.

Este projeto é independente e não possui vínculo oficial com a Pocketpair.
