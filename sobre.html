PROJETO COMUNITÁRIO

Sobre o projeto

Pal Forge é um projeto comunitário, não oficial e desenvolvido por fãs para reunir ferramentas e informações úteis sobre Palworld em um só lugar.

Objetivo

Reunir Palpedia, breeding, mutações, mapas, itens, equipes e rankings em ferramentas diretas, com regras e limitações apresentadas de forma transparente.

Tecnologias utilizadas

O site é estático e utiliza HTML, CSS e JavaScript, com publicação pelo GitHub Pages. Não depende de backend ou banco de dados para funcionar.

Filosofia do projeto

Priorizar informações verificáveis, ferramentas diretas e resultados reproduzíveis. Quando algo ainda não foi confirmado, a limitação deve ficar clara.

Fontes dos dados

Os dados vêm de datamine, estruturas nativas do jogo, testes e validações práticas. Evidências nativas têm prioridade sobre fontes externas, e limitações conhecidas são informadas quando necessário.

Projeto independente

Palworld pertence à Pocketpair.

Este projeto é independente e não possui vínculo oficial com a Pocketpair.
